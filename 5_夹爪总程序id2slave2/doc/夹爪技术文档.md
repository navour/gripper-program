## 2. 项目概述

本项目控制一套单电机自适应夹爪。STM32G431 通过 FDCAN 驱动达妙电机，通过 AS5048A 获得夹爪输出端绝对角度，通过两路 SPI 采集四组 8×4 压力阵列，并通过 USART2/RS485 提供 Modbus RTU 从站接口。FreeRTOS 将控制发送、传感器采集、通信与调试输出拆分为独立任务。

当前核心功能包括：

- 达妙电机 MIT、位置、速度等协议控制；实际夹爪目标跟踪默认使用 MIT 报文中的速度控制方式。
- AS5048A 14 位绝对角度作为夹爪机械位置主反馈。
- BE 端三组、LE 端一组压力阵列采集、基线校准、滤波、接触特征和超压锁存。
- 电机反馈力矩的滤波、摩擦补偿、外力矩/接触代理量估算。
- 到达目标、接触后保持、压力硬停、解锁卸压等控制策略。
- 机械零点、比例系数和坐标偏置的 Flash 记录。
- Modbus RTU 参数配置和状态读取。
- Python/Tkinter 调试上位机。

## 3. 系统组成与数据流

```text
PC 上位机
  │ Modbus RTU，USART2/RS485，115200-8-N-1，Slave=2
  ▼
dm_modbus_bridge.c ────── 参数/目标/安全状态/反馈寄存器
  │                       │
  │ 控制目标              ├── force_estimator.c（力矩/摩擦/接触估算）
  ▼                       └── pos_persist.c（Flash 持久化）
MOTORTask ── FDCAN1 ── 达妙电机
  ▲                         │位置/速度/力矩/温度反馈
  └─────────────────────────┘

AS5048ATask ── SPI1 ── AS5048A ── 机械绝对角度主反馈
PRESSURETask ─ SPI2/SPI3 ─ 压力板 ─ 特征/接触/安全锁存
UART1PrintTask ─ USART1 ─ 调试终端
```

## 6. 上电与任务执行流程

### 6.1 主程序启动

`Core/Src/main.c` 的顺序为：

1. `HAL_Init()` 和 160 MHz 系统时钟配置。
2. 初始化 GPIO、FDCAN1、USART1、TIM3、SPI1、SPI2、SPI3、USART2。
3. `bsp_can_init()`：配置 CAN 全通掩码过滤器、启动 FDCAN 和接收中断。
4. `dm_motor_init()`：清零电机结构并设置默认 ID `0x02`、MIT 模式、PMAX=20、VMAX=30、TMAX=10。
5. 初始化 CMSIS-RTOS2 对象和任务，启动调度器。

上电不会自动使能电机。Modbus 的 `ENABLE` 初值为 0，必须由主机明确使能。

### 6.2 FreeRTOS 任务

| 任务 | 优先级 | 栈 | 周期/行为 | 职责 |
| --- | --- | --- | --- | --- |
| `MOTORTask` | High | 4096 B | 延时 500 ms 后每 2 ms | 发送电机控制帧，约 500 Hz |
| `PRESSURETask` | Normal | 4096 B | 初始化后每 50 ms | 采集两路压力板、处理特征和安全状态 |
| `AS5048ATask` | Low | 2048 B | 每 50 ms | 更新绝对角、磁场值和有效状态 |
| `UART1PrintTask` | Low | 3072 B | 每 1 ms 调用打印状态机 | USART1 调试输出 |
| `ModbusTask` | Low | 2048 B | 初始化后每 1 ms | Modbus 轮询、目标跟踪、保护、反馈更新 |
| `LEDTask` | Low | 512 B | 每 500 ms | 翻转 PB1 心跳灯 |

`PRESSURE_SPI_DIAG_MINIMAL` 默认为 0。改为 1 时不会创建电机和 Modbus 任务，适合只诊断压力 SPI；正常固件必须保持 0。

## 7. 电机控制

### 7.1 分层

- `bsp_fdcan.c/h`：CAN 初始化、发送、接收和 HAL 回调。
- `dm_motor_drv.c/h`：达妙帧编码、使能、失能、清错、寄存器读写。
- `dm_motor_ctrl.c/h`：`motor[Motor1]` 状态、反馈分发和控制帧选择。
- `dm_modbus_bridge.c`：机械坐标目标、安全条件和上位机命令。

单电机默认 CAN ID 为 `0x02`。`DM_Bridge_Init(..., motor_id)` 当前没有使用传入的 `motor_id` 参数，而是读取 `motor[Motor1].id`，因此不要被 `app_freertos.c` 中的 `motor_id=1` 注释误导。

### 7.2 当前闭环方式

编译宏 `BRIDGE_USE_AS_VELOCITY_LOOP=1`，所以目标位置闭环以 AS5048A 为主：

```text
host_err = host_target - AS5048A_host_position
motor_velocity = Kp_as × scale × host_err
motor_velocity 限制在 ±(scale × host_velocity_limit)
```

默认 `Kp_as=8`，host 最大速度 45 deg/s，位置死区 0.5°。发送给达妙电机时保持当前电机位置，MIT `kp=0`、`kd=0.3`，通过速度项驱动。上电后的第一次运动还会限制到 5 deg/s，并清除力矩前馈。

机械坐标有效范围默认是 `-45°` 到 `+8°`。AS5048A 无效或角度越界时，固件把电机置为被动参数并阻止正常运动。寄存器 `0x0048` 写 `0xA55A` 可临时绕过 120 秒，只用于标定和排障，不可作为长期运行方案。

### 7.3 目标与接触保持

主机写入目标后，Modbus 桥缓存 P、V、Kp、Kd、TFF。目标位置由 AS5048A 每 20 ms 重新跟踪。闭合过程中，力矩估算达到 `grip_hold_th`，并满足最小行程、低速和连续 3 次确认后，固件锁定当前 host 位置，停止继续闭合；收到明确的打开目标后退出保持。

## 8. AS5048A 与坐标系

AS5048A 使用 SPI1 16 位 Mode 1。一次寄存器读包含命令和返回两个 SPI 事务，并检查奇偶校验和错误位。核心状态为：

| 变量 | 含义 |
| --- | --- |
| `angle_val` | 14 位角度原始值，0～16383 |
| `angle_deg` | 0～360°绝对角 |
| `mag_val` | 磁场幅值 |
| `angle_valid` | 当前角度有效 |
| `error_flag` | 读取错误标志 |

系统内部包含三种位置：

- AS 绝对角：传感器的 0～2π 原始机械角。
- host 机械角：以保存零点为基准，经 `wrap_pm_pi(as_abs-zero_abs)` 得到，供上位机和控制策略使用。
- motor 角：达妙电机反馈的转子/输出位置。

电机与 host 的辅助关系为：

```text
host_pos = motor_pos / scale + bias
motor_pos = scale × (host_pos - bias)
```

当前默认 `scale=26.5`。启动后不直接信任断电前的多圈电机坐标；收到第一帧电机反馈且 AS5048A 有效时，重新绑定 bias。这是避免达妙单圈零点/多圈计数变化导致突然跳转的关键保护。

## 9. 压力采集与安全保护

### 9.1 压力帧格式

| 总线 | 帧长度 | 格式 |
| --- | --- | --- |
| SPI3 / BE | 194 B | `0xA5 + B[32] + C[32] + E[32] + 0x5A`，每点 uint16 |
| SPI2 / LE | 66 B | `0xA5 + C[32] + 0x5A`，每点 uint16 |

代码用 `memcpy` 直接把字节装入 STM32 的 `uint16_t` 数组，因此压力板当前必须发送小端 16 位数据。帧头/帧尾连续错误 5 次会中止、反初始化并重新初始化对应 SPI。单帧失败时复用上一次有效特征。

### 9.2 信号处理

上电前 100 个有效帧用于各点基线平均。任务周期约 50 ms，因此无触碰条件下完整校准约需 5 秒。校准时必须让夹爪压力面完全无载，否则接触量会被吸收到基线中。

校准后每个点执行：

```text
delta = abs(raw - base)
filtered += (delta - filtered) / 4
```

之后计算 sum、max、area 和最大点坐标。单区接触条件为 `sum>=120` 或 `max>=30`；area 统计阈值为 8。当前 `ENABLE_BASE_TRACK=0`，运行期不自动漂移基线。

Modbus 发布 6 个区域：TOTAL、BE_SUM、BE_B、BE_C、BE_E、LE_C，每个区域 5 个寄存器（状态、sum 高低字、max、area），起始地址 `0x0130`。

### 9.3 压力硬保护

默认总和阈值 4500、单点最大阈值 1000，任一超限即锁存：

1. `PressureSafety_IsLatched()` 变为 1。
2. Modbus 桥把 `ENABLE` 清零并发送电机失能。
3. 即使压力随后下降也不会自动恢复。
4. 主机向 `0x0034` 写 `0xA55A` 后进入解锁等待。
5. 解锁等待期间只允许向打开方向运动以卸压。
6. 总和和最大值均低于各自阈值的 1/4，连续 5 帧后才重新允许正常闭合。

安全标志 `0x0106`：bit0 锁存、bit1 sum 超限、bit2 max 超限、bit3 解锁等待。

## 10. 力矩与夹持接触估算

`ForceEstimator_Update()` 约每 20 ms 使用 host 位置、电机速度和反馈力矩更新。处理链为：

```text
原始力矩 → 低通/零偏 → 粘滞+库仑+静摩擦模型
         → 扣摩擦外力矩 → 可选位置 baseline → 接触代理量
         → 阈值、方向及连续帧确认 → contact_flag
```

当前 `FORCE_EST_USE_POSITION_BASELINE=0`，虽然保留了 baseline 参数和反馈，接触判定默认不扣位置 baseline。默认接触阈值 0.080 Nm，夹紧保持阈值 0.220 Nm。摩擦和阈值参数映射在 `0x0036～0x0047`，反馈在 `0x010A～0x012C`；详见寄存器文档。

`force_proxy` 只是基于电机力矩模型的代理量，不等同于经过标定的牛顿力。若产品要求输出 N，必须用标准测力计建立机构姿态、接触点和力矩到夹持力的标定模型。

## 11. Modbus RTU 协议摘要

| 项目 | 当前值 |
| --- | --- |
| 物理层 | USART2 + RS485 半双工，PA1 控制 DE |
| 串口 | 115200 bit/s，8 数据位，无校验，1 停止位 |
| 从站地址 | `2` |
| 功能码 | `0x03` 读保持寄存器、`0x06` 写单寄存器、`0x10` 写多个寄存器 |
| CRC | Modbus CRC16，低字节先发送 |
| 寄存器表 | 512 个 uint16，地址 `0x0000～0x01FF` |
| 32 位顺序 | 高 16 位寄存器在前，寄存器内大端 |

最常用寄存器：

| 地址 | 作用 |
| --- | --- |
| `0x0000/0x0001` | 设备 ID `0xD431`、固件版本 `0x010F` |
| `0x0010` | 电机 CAN ID |
| `0x0011` | 模式：0 MIT、1 位置、2 速度 |
| `0x0012` | 使能/失能 |
| `0x0013` | 写 1 清电机故障 |
| `0x0014` | 单位配置，默认 `0x000F` |
| `0x0016` | 写 1 保存 AS 机械零点 |
| `0x0017` | 写 1 保存达妙电机零点 |
| `0x0020～0x0027` | V、P、Kp、Kd、TFF 目标块 |
| `0x0030～0x0032` | 压力安全阈值 |
| `0x0034` | 写 `0xA55A` 解锁压力保护 |
| `0x0048` | 写 `0xA55A` 临时绕过 AS 范围 120 秒 |
| `0x0100～` | 位置、故障、温度、力矩、AS、控制诊断反馈 |

注意：代码默认 `UNIT_CFG=0x000F`，即位置/速度均用度且 P/V 均为 x1；但 PC 工具快捷按钮会写 `0x000B`，其位置按 `deg×1000`、速度按 `deg/s×1`。发送目标前必须先统一 `UNIT_CFG`，否则位置会相差 1000 倍。建议当前 PC 工具流程统一使用 `0x000B`。

## 12. 代码如何使用

### 12.1 首次准备

需要：

- Keil MDK-ARM 5，工程现有构建记录使用 ARM Compiler 5.06 update 5。
- STM32G4 Device Family Pack；现有构建记录为 `Keil.STM32G4xx_DFP 2.1.0`。
- ST-Link 和 SWD 接口。
- Python 3、Tkinter、pyserial（运行上位机）。
- USB-RS485 适配器，确认 A/B 极性和共地。
- FDCAN 收发器与正确终端电阻；MCU 引脚不能直接连接 CANH/CANL。

不要把 `.ioc` 重新生成代码作为首次操作。工程存在多处手工修改；如需 CubeMX 重新生成，应先备份并检查所有 `USER CODE` 外的差异。

### 12.2 编译固件

1. 用 Keil 打开 `MDK-ARM/JIAZHUA_RTOS.uvprojx`。
2. 选择 Target `JIAZHUA_RTOS`，不要误用目录中的旧目标或压力板独立工程。
3. 确认 Device 为 STM32G431CBTx，编译器为 ARMCC 5。
4. 执行 Rebuild。
5. 成功后产物位于 `MDK-ARM/JIAZHUA_RTOS/`，主要是 `.axf` 和 `.hex`。

仓库中最近保留的成功日志显示：0 Error、0 Warning，Code 44336 B、RO 1348 B、RW 384 B、ZI 29744 B。该日志只代表当时构建，不代表任何修改后仍然通过，因此每次交付都必须重新编译。

### 12.3 烧录与上电前检查

1. 机械上先确保夹爪可自由运动，移除易碎工件。
2. 暂时断开或关闭电机动力电源，只给主控供电检查 3.3 V、时钟和串口。
3. 用 ST-Link 通过 SWD 烧录 `.axf` 或 `.hex`。
4. 启动调试时观察是否进入 `Error_Handler()`；若卡死，优先检查 HSE、外设初始化和供电。
5. PB1 每约 1 秒完成一个亮灭周期，表示调度器与 LED 任务仍运行。
6. 接入 USART1 115200，确认 AS 和压力诊断有更新。
7. 压力面保持无载至少 5 秒，等待 100 帧基线校准完成。
8. 最后接通电机动力和 CAN。

### 12.4 运行上位机

在 PowerShell 中进入工程目录后运行：

```powershell
python -m pip install pyserial
python PC_Tool\3_gripper.py
```

Tkinter 通常随 Windows Python 安装；若提示缺少 `tkinter`，需换用包含 Tcl/Tk 的官方 Python 安装。

界面连接参数：

- COM：USB-RS485 对应端口。
- Baud：`115200`。
- Slave：必须手动填 `2`。

推荐首次联调顺序：

1. 连接串口后先读设备/实时反馈，确认 `DEV_ID=0xD431`、`FW_VER=0x010F`。
2. 设置 MIT 模式。
3. 写单位配置 `0x000B`。
4. 查看 AS 状态有效、host 角度在 `-45°～+8°`。
5. 查看所有压力区域 calibrated=1，空载 sum/max 较小。
6. 先发送低速度、小幅度打开目标，保持未使能。
7. 确认目标单位和方向无误后使能。
8. 再逐步测试闭合、接触保持和压力保护。

### 12.5 首次标定

推荐在无工件、低速、随时可断电的条件下执行：

1. 确认 AS5048A 原始角连续且无错误。
2. 如因旧零点导致越界而无法移动，可向 `0x0048` 写 `0xA55A` 临时解除范围保护；两分钟后自动恢复。
3. 低速移动到定义的机械零位。
4. 向 `0x0016` 写 1，保存当前 AS 位置和比例。
5. 如确实需要重设达妙自身零点，再向 `0x0017` 写 1；此动作会改变电机坐标，必须避免带载执行。
6. 失能并重新上电。
7. 读取 `0x0018～0x001F`，确认持久化有效，并验证 host 位置、方向和范围。
8. 做一次小幅首次运动，确认首次限速生效且没有跳变。

Flash 记录区从 `0x0801F800` 开始，大小 0x800 B，即 STM32G431 128 KB Flash 的末页。修改链接脚本、Bootloader 或固件尺寸时必须保留此页，禁止代码段覆盖。

### 12.6 正常开合

使用 PC 工具并采用 `UNIT_CFG=0x000B` 时：

- P：输入角度，工具按 `deg×1000` 写入 32 位寄存器。
- V：输入 deg/s，x1 写入。
- Kp/Kd：工具分别按 ×100 写入；AS 速度环开启时目标跟踪主要受固件 `BRIDGE_AS_VEL_KP` 和 V 限制控制，界面 Kp 并非最终位置环增益。
- TFF：按 Nm×1000 写入；首次运动会被清零，正常使用也应谨慎。

建议先写完整目标块，再写 `ENABLE=1`。停止时先写 `ENABLE=0`，不要仅依赖把速度写成 0。

### 12.7 压力报警后的恢复

1. 上位机确认 SAFE bit0=1；此时电机已失能。
2. 排查工件卡死、阈值过小、压力板基线错误或传感器数据异常。
3. 写 `0x0034=0xA55A`。
4. 系统进入 ARMING，只允许打开方向卸压。
5. 压力降到阈值 1/4 以下并连续保持约 250 ms 后，bit3 清除。
6. 重新下发安全目标，再重新使能。

禁止通过反复提高安全阈值掩盖机械卡死或传感器故障。

## 13. 调试与故障定位

| 现象 | 优先检查 |
| --- | --- |
| 上位机无响应 | Slave 是否为 2；115200；A/B 极性；PA1 DE；共地；USART2 中断 |
| 有请求但无回包 | CRC、功能码、地址范围；逻辑分析仪查看 PA2/PA3/PA1 |
| 电机不动 | `ENABLE`、SAFE flags、AS status、AS 是否越界、CAN 1 Mbit/s、电机 ID=2 |
| 电机上电突然动作 | 立即断动力；检查零点、scale/bias、目标单位和 P 是否放大 1000 倍 |
| 只能第一次动/随后停 | 查看接触保持、force proxy、`REG_EST_GRIP_TH` 和压力锁存 |
| AS 无效 | SPI1 Mode 1、PA4 CS、磁铁间距/偏心、奇偶错误、3.3 V |
| 压力一直未校准 | 帧头 A5/帧尾 5A、SPI 线、端序、是否持续得到有效帧 |
| 空载压力很高 | 上电校准时受力、压力板零漂、端序错误、帧错位 |
| CAN 无反馈 | 收发器供电、终端电阻、CANH/L、1 Mbit/s、ID、FDCAN 中断 |
| PB1 不闪 | 调度器未启动、HardFault/Error_Handler、供电/时钟异常 |

推荐诊断顺序始终是：电源与物理层 → 心跳与 USART1 → AS/压力有效性 → Modbus 状态 → CAN 反馈 → 最后才使能运动。

## 14. 中断与并发注意事项

- FDCAN FIFO0 中断调用 `fdcan1_rx_callback()`；寄存器协议 ID `0x7FF` 单独解析，其他标准反馈转给 Modbus 桥。
- USART2 使用 Receive-to-Idle 中断收帧，发送完成后切回接收；发送超过 20 ms 会中止并恢复接收。
- SPI2/3 当前采集函数实际使用阻塞式 `HAL_SPI_TransmitReceive()`。虽然仍保留共享 `SpiRxSem` 和完成回调，正常阻塞路径并不依赖该信号量。
- 压力特征读取用短暂关中断保护结构体复制；电机和 Modbus 状态大多依靠单生产者/轮询时序，没有统一互斥锁。新增跨任务的多字节共享状态时应增加临界区、队列或互斥量。
- `printf` 经 USART1 阻塞发送单字符，过量打印会占用 CPU 并扰动低优先级任务。

### 15.3 修改压力板格式

同时修改帧缓冲大小、头尾索引、各数组 `memcpy` 偏移、端序转换和压力板发送端。不可只调整数组长度。修改后用固定模式数据验证 32 个点的顺序。

### 15.4 修改机械范围或减速比例

需要联合检查：

- `BRIDGE_POS_SCALE_DEFAULT`
- `BRIDGE_AS_HOST_MIN_DEG` / `MAX_DEG`
- Flash 中已保存的 scale、zero 和 bias
- 达妙 PMAX 与 `BRIDGE_MOTOR_POS_LIMIT_MARGIN`
- PC 工具目标范围
- 力矩估算 baseline 的开合位置

修改默认值不会覆盖已有 Flash 记录。测试新参数前应明确是否需要重新标定或擦除末页。

### 15.5 修改安全策略

压力硬锁存与力矩接触保持是两套机制：前者用于超压失能，后者用于正常夹持停止闭合。不要用接触保持代替硬保护，也不要让模式切换、清错或重新使能绕过 `PressureSafety_IsLatched()`。

## 16. 当前已知问题与交接风险

1. 固件 Modbus 地址为 2，上位机默认地址为 1；每次连接必须手动修改，后续建议统一代码默认值。
2. `doc/PC_Tool_寄存器大全.md` 的固件版本仍写 v1.13，当前源码是 v1.15。
3. `app_freertos.c` 调用 `DM_Bridge_Init(..., 1)`，但参数被函数忽略；真实电机 ID 默认是 2。
4. `UNIT_CFG` 固件初值 `0x000F`，PC 工具常用值 `0x000B`；不先统一单位可能产生 1000 倍目标错误。
5. 压力帧直接 `memcpy` 为 uint16，协议隐含依赖小端。
6. SPI 完成信号量与当前阻塞式采集并存，属于历史实现残留，修改成中断/DMA 前应重新设计每路 SPI 的完成同步。
7. 当前没有独立看门狗、CAN 反馈超时失能或任务栈溢出报警的完整产品级实现；量产/无人值守前应补齐。
8. `Error_Handler()` 只关中断死循环，没有故障码输出。
9. 力量反馈是代理量，不是标定后的物理牛顿值。
10. 工程目录当前未检测到 Git 元数据；正式交接应纳入版本控制并记录硬件版本、固件 hex 哈希和标定参数。
