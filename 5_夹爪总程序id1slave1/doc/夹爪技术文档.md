# 1. 项目概述
# 1.1 产品简介
本文档介绍了夹爪的整体控制架构，系统通过 FDCAN 总线驱动达妙 DM4310 电机实现夹爪开合动作，同时集成 AS5048A 磁编码器获取绝对角度、压力传感器阵列实现夹持力检测，并通过 Modbus RTU 协议与上位机通信，实现远程控制与状态监测。
# 1.2 核心功能
| 功能 | 说明 |
| --- | --- |
| 电机控制 | 支持 MIT（力位混控）、位置、速度、位置-速度-电流混控四种模式 |
| 角度检测 | AS5048A 14位磁编码器，分辨率 0.022°，提供绝对角度反馈 |
| 压力检测 | 8×4 压力传感器阵列（大端 BE 5组 + 小端 LE 3组），实时计算接触力特征 |
| 阈值报警 | 压力超阈值自动锁存停机，防止夹爪过载损坏工件或机构 |
| Modbus 通信 | RS485 半双工 Modbus RTU，上位机可读写全部控制/反馈寄存器 |
| 零点持久化 | AS5048A 机械零点保存至 Flash，掉电不丢失 |

# 3. 夹爪控制逻辑流程图
# 3.1 预运行

3-1 预运行流程图
预运行阶段的目标是：在电机不动作的前提下完成系统初始化、参数装载、传感器联通性确认，并进入可接收上位机指令的待命状态。该阶段主要包含以下步骤：

# 1.系统上电与基础初始化：进行 MCU 外设初始化（GPIO、UART/RS485、FDCAN/SPI 等），并完成与上位机通信所需的串口通道准备。
# 2.传感器启动：对 AS5048A 进行首次读取与状态确认，确保采样链路可用，同时启动压力传感器采集任务的基础初始化。
# 3.读取 Flash 持久化参数：从 Flash 中装载系统关键参数（如零点、开合极限、单位配置、安全阈值、默认控制参数等），确保系统以上次标定/保存的参数启动，避免每次上电都需要重新标定。
# 4.进入 FreeRTOS 多任务调度：启动 ModbusTask、MOTORTask、AS5048ATask、PRESSURETask 等任务。此时系统进入“待命/可控”状态，等待上位机指令触发进入运行阶段。
## 5.等待上位机 Modbus 指令触发：若未收到有效控制指令（或尚未使能/未解锁），系统保持待命，收到指令后进入 3.2 运行流程。


# 3.2 运行

3-2 运行流程图
运行阶段的核心是：上位机通过 Modbus 下发目标，单片机侧解析指令并驱动电机执行，同时以固定周期刷新位置与压力反馈，并在后台持续进行安全判定。整体逻辑具体如下：
# 1.上位机下发控制指令（Modbus RTU）：上位机发送位置/开合度/控制参数（如 V、P、Kp、Kd 等）到指定寄存器区域。ModbusTask 负责接收、校验 CRC、解析功能码与寄存器写入，并更新内部控制目标。
# 2. 电机控制任务执行目标（MOTORTask）：MOTORTask 根据最新目标与单位配置，生成电机侧控制量（如目标位置、速度限制、增益等），并通过 FDCAN/驱动接口向电机发送控制报文，实现夹爪开合动作。
# 3.位置采集与状态刷新（AS5048ATask / UART 打印任务）：AS5048ATask 周期性读取角度数据，通过上位机读取和串口打印，用于实时显示当前角度，并计算开合度映射作为控制逻辑与安全判断的辅助参考。
## 4.压力采集与安全状态计算（PRESSURETask）：PRESSURETask 周期采集压力阵列数据，提取关键特征量（如 sum/max 等），并依据阈值规则进行安全判断：若压力处于正常范围，系统持续运行；若压力超过安全阈值，触发 SAFE 锁存，进入 3.3 报错流程。
# 3.3 报错

3-3 报错流程图
报错流程由两部分组成：监控阶段与故障处理阶段。其中监控阶段负责识别异常并设置系统错误源，故障处理阶段负责执行失能、提示、等待解锁与恢复运行。
监控阶段在系统主循环中持续对两类关键风险进行判定：一是电机侧状态与故障码（如过压、欠压、过流、过温、过载、通讯丢失等），二是压力特征量是否超过安全阈值。一旦任一条件满足，即认为系统进入异常状态，立即置位对应错误标志，系统状态切换至错误，为后续的强制保护与恢复流程提供统一入口。
故障处理阶段在系统进入错误后首先切断电机力矩，执行失能，防止夹爪继续运动或持续夹持导致风险扩大。同时向上位机上报错误原因并提示用户排查方向，随后系统进入等待恢复状态，要求用户执行解锁操作，并在恢复前进行二次确认（。确认异常解除后，系统退出错误态，恢复到可运行或待命状态，允许重新接收控制指令并继续工作。

## 5.2.2 工作原理
接口：SPI1，16bit 模式，CPOL=0 / CPHA=1，1.25 Mbps
分辨率：14 位（16384 步 / 360°），精度约 0.022°
协议：两次 SPI 传输完成一次读取（第一次发命令，第二次收数据）
校验：偶校验位 + 错误标志位检测
延时：使用 DWT 硬件计数器实现微秒级精确延时

| --- | --- | --- |

| mag_val | uint16_t | 磁信号幅值 |
| error_flag | uint8_t | 错误标志 (0=正常) |

## 5.2.4 作用
AS5048A 提供夹爪的绝对角度，用于：
建立 host 机械坐标系（以保存的零点为原点，±π 范围）
掉电后恢复位置（无需回零操作）

## 5.3.2 信号处理
系统配置了两路 SPI 总线用于压力阵列数据采集：
SPI3（CS: PB6）：大端BE传感器阵列，一帧 322 字节，包含 3 组 32 路数据（BE_C / BE_D / BE_E），合计 96 路；
SPI2（CS: PB12）：小端LE传感器阵列，一帧 194 字节，包含 1 组 32 路数据（LE_C）。
在信号处理的过程中，系统首先采集压力阵列的原始数据 raw。在上电后的校准阶段，对前 100 帧数据进行累加并求平均，得到各采样点的基线值 base，用于补偿零漂与静态偏置。随后对每个采样点计算 delta = raw - base，并将负值钳位为 0,仅保留正向压力变化。为抑制噪声与抖动，系统对 delta 进行一阶 IIR 低通滤波，采用递推形式 y += (delta - y) >> 2，等效滤波系数 β=1/4。滤波后的阵列数据用于特征提取,sum 为所有点滤波值之和，用于表征总压力；max 为单点最大值，用于表征峰值压力；area 为超过指定阈值的点数，用于近似接触面积；max_r/max_c 为最大值所在的行/列位置，用于定位受力中心或峰值点。同时通过接触判定条件（例如 sum ≥ 4500或 max ≥ 1000）生成 contact 标志，用于判断夹爪是否与物体发生有效接触。

# 5.4 Modbus 桥接模块
## 5.4.1 文件组成
| 文件 | 职责 |
| --- | --- |
| dm_modbus_bridge.c/h | Modbus RTU 从站、寄存器映射、坐标变换、安全策略 |

## 5.4.2 核心职责
Modbus 桥接模块是系统的中枢，负责：
解析上位机 Modbus RTU 命令（功能码 03/06/10）
维护 512 个 16-bit 寄存器的映射表
将上位机目标参数转换为电机控制参数（坐标变换）
将电机反馈数据转换为上位机可读的寄存器值
执行安全策略（压力锁存、方向限制）
管理电机使能/失能/清错/模式切换
## 5.4.3 坐标变换
夹爪系统中拥有两套坐标系：
| 坐标系 | 范围 | 用途 |
| --- | --- | --- |
| motor 坐标 | 电机内部 rad | 电机控制帧使用 |
| host 机械坐标 | 以 AS5048A 零点为原点，±π rad | 上位机使用 |

变换公式为：
host_pos = motor_pos / scale + bias
motor_pos = scale × (host_pos - bias)
其中scale = 46.4（默认减速比），bias 在首次收到电机反馈时自动计算，优先使用 AS5048A 绝对角度

# 7. 安全机制
# 7.1 压力阈值锁存保护
本系统实现压力阈值锁存保护机制，以 REG 0x0106 的安全标志位（flags）作为核心控制量，通过阈值判定、 锁存标志、解锁指令以及重武装计数的条件分支实现保护行为。
## 7.1.1 状态说明
| 状态 | 电机 | 允许操作 | 触发条件 |
| --- | --- | --- | --- |
| NORMAL | 正常控制 | 全部 | 默认状态 |
| LATCHED | 强制失能 | 无 | 压力 sum ≥ 阈值 或 max ≥ 阈值 |
| BLOCKED | 可使能 | 仅"开"方向，速度限 30°/s | 上位机写 UNLOCK=0xA55A |
| RE-ARM | 恢复正常 | — | 压力降至阈值 1/4 以下，连续 5 帧 |

## 7.1.2 默认阈值
| 参数 | 默认值 | 寄存器 |
| --- | --- | --- |
| sum 阈值 | 4500 | 0x0030~0x0031 |
| max 阈值 | 1000 | 0x0032 |

## 7.1.3 安全标志位 (REG 0x0106)
| Bit | 名称 | 说明 |
| --- | --- | --- |
| 0 | LATCHED | 锁存激活 |
| 1 | SUM_OVER | 当前 sum 超阈值 |
| 2 | MAX_OVER | 当前 max 超阈值 |
| 3 | ARMING | 解锁后等待重武装 |

# 7.2 电机故障保护
电机通过 CAN 反馈帧上报错误码 ERR，反馈帧为 D[0]=ID | (ERR<<4)，其中 ERR 为高 4 位。
固件解析反馈帧后，将 ERR 映射到寄存器 REG_FB_ERR (0x0103)；部分旧版本固件可能直接保存 D[0] 原值（上位机需取高 4 位得到 ERR，低 4 位为 ID 低位）。上位机可写 REG_CLEAR_FAULT (0x0013) = 1 清除故障并重使能清错时若处于 LATCHED 状态，不会重使能。
# 7.3 通信容错
| 场景 | 处理方式 |
| --- | --- |
| Modbus CRC 错误 | 返回异常帧 (code=0x03) |
| UART 溢出错误 | 清除 ORE 标志，重启接收 |
| SPI 超时 | abort + 重试，保持上次有效值 |
| SPI 帧头帧尾不匹配 | 丢弃本帧，使用上次有效值 |
| CAN Bus-Off | 自动清除 INIT 位恢复 |

# 8. 数据持久化
# 8.1 存储方案
| 参数 | 值 |
| --- | --- |
| 存储区域 | Flash 最后一页 (0x0801F800, 2KB) |
| 记录大小 | 24 字节 (3 × doubleword) |
| 页容量 | 85 条记录 |
| 写入策略 | 追加写，页满时擦除重写 |
| 校验方式 | CRC32 (以太网标准多项式) |

# 8.2 记录格式
| 偏移 | 大小 | 字段 | 说明 |
| --- | --- | --- | --- |
| 0x00 | 4B | magic | 魔数 0x505A524F ('PZRO') |
| 0x04 | 4B | seq | 序列号（递增，用于找最新记录） |
| 0x08 | 4B | pos_mrad | 机械零点绝对角度 (mrad, int32) |
| 0x0C | 4B | scale_milli | 减速比 × 1000 (int32) |
| 0x10 | 4B | crc32 | 前 16 字节的 CRC32 |
| 0x14 | 4B | rsv | 保留 (0xFFFFFFFF) |


# 8.3 读取流程
# 1. 上电时遍历整页，找到 magic 匹配且 CRC 校验通过的最新记录（seq 最大）
# 2. 恢复 s_zero_abs_rad（机械零点）和 s_loaded_scale（减速比）
# 3. 若无有效记录，以当前 AS5048A 读数为临时零点（不写 Flash）
# 8.4 写入触发
仅在上位机显式写入 REG_SAVE_ZERO (0x0016) = 1 时触发
取当前 AS5048A 绝对角度作为新零点
允许页满擦除（allow_erase = 1）
写入后同步更新 bias，保证坐标映射连续

附录A  故障码（ERR）含义
电机红灯闪烁代表故障状态，需排障后清错再使能。
| 故障码 | 含义 |
| --- | --- |
| 0x8 | 超压（Over-voltage） |
| 0x9 | 欠压（Under-voltage） |
| 0xA | 过电流（Over-current） |
| 0xB | MOS 管过温（MOS Over-temp） |
| 0xC | 线圈过温（Coil Over-temp） |
| 0xD | 通讯丢失（Communication Lost） |
| 0xE | 过载（Overload） |

错误码 ERR 来自电机反馈帧的故障类型字段，用于提示电机驱动的保护状态。ERR=0 表示正常；ERR≠0 表示存在保护/故障，需优先排除电源、负载与温升问题。
同时，上位机在实时读取开启时，会周期读取 REG_FB_ERR (0x0103) 与温度寄存器；当检测到 ERR≠0 时，界面将提示报警信息，并建议执行：① 立即失能(0x0012=0)；② 排查电源/线束/机构卡滞；③ 写 0x0013=1（清错并重使能）后观察 ERR 是否恢复为 0。
